# 仕様変更書 005：メインクエスト・ゲーム進行の明確化

- 対象：Night Flow MVP
- 優先度：高
- 変更理由：施設を修復するだけでは、なぜ開拓するのか、最終目的は何か、次に何をすべきかが伝わりづらい。

## ゲームの目的

かつて空の航路を照らしていた「星渡りの灯台」が消え、浮遊島群は孤立した。プレイヤーは漂着した拠点を再建し、研究・探索・育成の力を組み合わせて灯台を再点灯し、群島の航路をつなぎ直す。

## MVPのメインクエスト

1. **最初の拠点を取り戻す**：研究施設・探索港・生息地のうち1つを選んで修復する。
2. **最初の開拓プロジェクトを完了する**：選択した施設が解放する機能を使い、最初の成果を得る。
3. **二つ目の施設を修復する**：異なる専門性を持つ施設を追加し、ルートを広げる。
4. **二つ目の開拓プロジェクトを完了する**：灯台の再点灯に必要なもう一つの成果を得る。
5. **星渡りの灯台を再点灯する**：二施設・二プロジェクト・開拓資材8個を条件として実行。新しい群島エリアを解放する。

## UI変更

- ホームと拠点画面に「メインクエスト」カードを表示。
- 現在の目的、目的の理由、進捗率、次の操作を表示。
- 開拓プロジェクト画面に最終目標と必要条件を表示。
- 目標の条件未達時は、不足している項目を明示する。
- 目標達成後は灯台再点灯と航路再接続を明示する。
- 初回チュートリアルに世界の背景・最終目的・開拓の意味を追加する。

## 報酬

- 1つ目の開拓プロジェクト完了時に資材3個。
- 2つ目の開拓プロジェクト完了時に資材5個。
- 灯台再点灯時にXP40、資材10個、新しい群島エリア、特別な遺物を獲得する。
- 既存施設や解放済み地域はルート変更で失われない。

## 受入条件

- 初回利用者が「なぜこの島を開拓するのか」を説明できる。
- ホーム・拠点で次に行うべきアクションが分かる。
- 進行状況に応じてメインクエストの段階が更新される。
- 必要条件を満たさなければ灯台再点灯は実行できない。
- 灯台再点灯後に新しい群島エリアと報酬が保存される。
