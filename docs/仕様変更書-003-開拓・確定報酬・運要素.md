# 仕様変更書 003：開拓の選択肢・報酬価値・ポジティブな運要素

- 対象：Night Flow MVP
- 変更理由：施設修復だけでは戦略性が薄く、学習で得た資材を使う価値と継続的なリターンが不足している。
- 優先度：高

## 変更内容

1. 研究施設は知識アーカイブ、探索港は遠征機能、生息地は仲間の育成機能を解放する。
2. 探索港の修復後、学習セッションの結果保存に応じて遠征券を獲得できる。遠征券は最大3枚まで保持する。
3. 遠征先は複数の選択肢からユーザーが選ぶ。航路ごとに費用・最低保証・追加報酬の特徴を変える。
4. すべての遠征に最低保証報酬を明記し、最低保証だけでも費用差引後の資材がプラスになるようにする。
5. ランダム要素は追加資源・珍しい遺物などの上振れに限定する。失敗、報酬減額、資材没収は実装しない。
6. 遺物の重複発見時にも資材補償を付け、報酬が無価値にならないようにする。
7. 開拓プロジェクト完了時には、地域解放・アーカイブ・仲間など永続的な機能を付与する。
8. 新規開拓可能通知は拠点・ホームに控えめに表示し、自動で建設画面を開かない。

## 報酬保証ルール

ユーザーに表示する最低保証は、乱数結果に関係なく必ず受け取れる。ランダム判定は最低保証に加算するだけであり、表示された最低値を下回る結果は生成しない。希少なサプライズ報酬は低確率の追加発見として扱う。

## 受入条件

- 施設ごとに明確な固有効果がある。
- 遠征はユーザーが航路を選んで開始する。
- 遠征費用と最低保証、差引の利益が開始前に見える。
- どの抽選結果でも最低保証を下回らない。
- 追加資源・遺物は上乗せされる。
- 同じ結果の再操作で遠征券や資源が二重に消費・付与されない。
- ゲーム画面は21:45〜23:20のルーティン中に表示・操作できない。
