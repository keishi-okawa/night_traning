# 仕様変更書 002：初回オンボーディング・チュートリアル

- 対象：Night Flow MVP
- 変更理由：初回起動直後に画面を表示するだけでは、夜のルーティン・学習・開拓ゲームの使い方が分からない。
- 優先度：高

## 変更内容

1. 初回起動時にステップ式チュートリアルを自動表示する。
2. 内容は、アプリの目的、夜の時間割、基本情報技術者試験の学習手順、3施設の選択と開拓、報酬・保存のルールで構成する。
3. 「次へ」「戻る」「スキップ」「Night Flowを始める」を提供する。
4. 完了状態をLocalStorageに保存し、通常起動時に再表示しない。
5. 設定画面からいつでも再表示できる。
6. チュートリアルは現時刻のフェーズを妨げず、終了後は現在時刻に対応した画面へ戻る。

## 受入条件

- 初回起動で説明が順番に表示される。
- スキップまたは完了後、次回起動では自動表示されない。
- 設定画面から再表示できる。
- 21:45〜23:20の時間帯に初回起動した場合も、チュートリアル終了後は正しいルーティン画面へ戻る。
