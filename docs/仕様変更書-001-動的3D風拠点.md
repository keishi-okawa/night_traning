# 仕様変更書 001：動的な3D風拠点・施設表現

- 対象：Night Flow MVP
- 変更理由：従来の静止画と絵文字マーカーでは、施設の種類・修復状態・島の変化が伝わらない。
- 優先度：高

## 変更内容

1. 島のシーンを、雲・滝・風・草木・樹木・飛行船・光が常時動くSVGシーンに置き換える。
2. 研究施設・探索港・生息地をそれぞれ固有の立体イラストとして描画する。
3. 修復済み施設は拠点シーン内に配置し、未修復施設は現地の基礎跡として表示する。
4. 施設詳細画面でも同じ固有イラストを大きく表示する。
5. 建設時は施設に近づくような拡大・浮上・光の演出を自動再生し、建設前・修復中・完成の段階を示す。再生ボタンは設けず、スキップは可能とする。
6. `prefers-reduced-motion` を尊重し、動きを抑制できるようにする。

## 技術方式・制約

MVPでは外部3Dエンジンや動画ファイルを追加せず、SVGの立体描画、SVG内アニメーション、CSSの遠近・浮遊・揺れ・パララックス風表現を組み合わせた2.5D方式とする。これはリアルタイムWebGL 3Dではない。オフライン性と単一HTML中心の軽量構成を優先する。

## 受入条件

- 拠点を表示すると、再生操作なしで雲・滝・草木・飛行船などが動く。
- 研究施設・探索港・生息地が、それぞれ見分けられる固有の建物として表示される。
- 建設状態に応じて拠点上の施設表示が変化する。
- 建設演出は自動再生し、途中スキップできる。
- 低モーション設定時にアニメーションを抑制する。
