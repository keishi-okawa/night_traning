# 仕様変更書 004：リアルタイム3Dモデル・WebGL拠点

- 対象：Night Flow MVP
- 優先度：高
- 変更理由：SVG/CSSの2.5D表現では、施設の立体感・カメラ操作・素材の質感が限定的だった。ユーザーの希望に合わせ、容量が増えてもリアリティを優先する。

## 変更内容

1. Three.js r187をローカル同梱し、CDNへの常時依存なしでWebGLシーンを構築する。
2. 浮遊島の地形を手続き生成メッシュで構成し、岩肌・草地・崖・滝・浮遊岩・植生を配置する。
3. 研究施設は観測塔と天文ドーム、探索港は木製桟橋・係留柱・飛行船、生息地はガラス温室・内部植生・仲間を別々の3Dモデルとして描画する。
4. PBRマテリアル、表面凹凸、環境反射、フォグ、複数光源、シャドウを利用する。
5. 雲・島・樹木・滝・飛行船・浮遊粒子を自動アニメーションする。再生ボタンは設けない。
6. ドラッグでカメラ回転、ホイール・ピンチでズームできる。
7. 建設中は対象施設にカメラを寄せ、建設前・建設中・完成の演出を再生する。
8. WebGL非対応または初期化失敗時はSVGシーンへフォールバックする。
9. `prefers-reduced-motion` を尊重し、アニメーションを抑制する。
10. 3DライブラリのMITライセンスを同梱する。

## 技術方式

- Three.js r187（`assets/vendor/`）
- シーン実装：`assets/js/island-3d.js`
- 地形・建物：実行時に生成するProcedural Mesh
- テクスチャ：CanvasTextureによる同梱生成
- PWA：Service WorkerでThree.js本体・コア・シーンモジュールをキャッシュ

本方式はリアルタイムWebGL 3Dであり、動画ファイルや単なる画像切替ではない。モデルは手続き生成で、外部のGLB/FBXモデルを読み込む方式ではない。

## 受入条件

- 拠点画面にWebGLの3Dシーンが表示される。
- ドラッグで視点が回転し、ピンチ・ホイールで拡大縮小できる。
- 研究施設・探索港・生息地がそれぞれ異なる形状・素材の建物として表示される。
- 建物修復後に拠点シーンへ3Dモデルが反映される。
- 雲・滝・木々・飛行船などが自動的に動く。
- 画面遷移でWebGLリソースが破棄され、再表示時に再生成される。
- Three.js関連ファイルがService Workerのキャッシュ対象である。
- WebGL非対応時にSVGフォールバックが表示される。
