# Night Flow 試用ガイド

## 公開URL

https://keishi-okawa.github.io/night_traning/

GitHub Pagesの初回設定が必要な場合は、Settings → Pages → Build and deployment → Source を「GitHub Actions」にします。設定後、Actionsの「Deploy Night Flow preview」を再実行します。

## 最初にすること

1. ホームでメインクエスト「星渡りの灯台」を確認する。
2. 拠点で研究施設・探索港・生息地のどれかを選ぶ。
3. 施設の詳細で3Dモデルをドラッグ・ピンチして確認する。
4. 「今日」では学習単元の要点を確認する。
5. 「ガント」で試験日・曜日・学習時間・問題数を設定し、自動計画を作る。
6. 「開拓」で資材・施設・プロジェクト・灯台再点灯を確認する。

## スマートフォンで試す

- Chrome / Safariの最新版を推奨。
- 3Dはドラッグまたはスワイプで回転。
- 2本指でピンチするとズーム。
- WebGL非対応時は島の画像に切り替わります。
- 3Dの初回読込に少し時間がかかる場合があります。

## データの扱い

データは現在のブラウザのLocalStorageに保存されます。ブラウザデータを削除する前に「設定」からJSONバックアップを取得してください。別端末間の同期機能はありません。
