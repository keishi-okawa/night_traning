# Night Flow MVP

夜のルーティン、基本情報技術者試験の学習、浮遊島の開拓シミュレーションをひとつにつなぐ個人用PWAです。

## 今回の修復内容

### 動く浮遊島・施設ビジュアル
- 島のシーンはSVGで構成し、雲・滝・草木・樹木・飛行船・ランタン・光粒子が再生ボタンなしで自動的に動きます。
- 研究施設・探索港・生息地は専用に生成した3DアイソメトリックWebP素材で表示し、浮遊・発光・カメラ接近風ズームを組み合わせます。
- 修復済み施設は拠点シーン上に現れ、未修復施設は基礎跡として表示されます。
- 建設時は施設に近づくような拡大・浮上・光の演出を3段階で再生し、スキップも可能です。
- `prefers-reduced-motion` に対応します。

> 表現方式はSVGとCSSアニメーションによる2.5Dです。WebGL/Three.jsのフル3Dエンジンや動画ファイルではありません。軽量性とオフライン動作を優先しています。

### 初回チュートリアル
- 初回起動時に6ステップのガイドを表示します。
- 「次へ」「戻る」「スキップ」に対応し、完了状態はLocalStorageに保存します。
- 設定画面から再表示できます。

### 開拓・報酬の強化
- 研究施設は知識アーカイブ、探索港は遠征、生息地は仲間の育成機能を解放します。
- 探索港の修復後、学習結果の保存で遠征券を獲得します（最大3枚）。
- 遠征先を選び、確定報酬に追加資源・希少遺物が上乗せされる仕組みを追加しました。
- 運要素で失敗したり、表示された最低保証を下回ったり、資材を没収されたりすることはありません。
- 遺物が重複した場合も資材補償があります。

## 起動方法

HTTPSまたはlocalhostで配信してください。`file://`ではService Workerは動作しません。

```powershell
py -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。GitHub Pagesでは Settings → Pages → Deploy from a branch → `main` またはこの修復ブランチ → `/(root)` を選択します。

## 主なファイル

- `index.html`：HTML/CSS/JavaScriptをまとめたアプリ本体
- `manifest.webmanifest`：PWA設定
- `sw.js`：アプリ本体とSVGアセットのオフラインキャッシュ
- `assets/game/island-scene.svg`：自動アニメーションする浮遊島
- `assets/game/facility-*.webp`：施設ごとの3Dレンダー素材
- `assets/game/facility-*.svg`：軽量SVGフォールバック
- `docs/`：今回の仕様変更書3件

## 既知の制約

- 過去問道場の成績自動取り込みは未実装です。演習結果はNight Flow側で入力してください。
- 過去問道場の分野は外部サイトを開いた後に選択します。非公開APIやスクレイピングには依存しません。
- カリキュラムはIPAシラバスVer.9.2の分類カタログです。すべての要点コンテンツが完成済みという意味ではありません。
- 学習・ゲームデータはLocalStorageに保存されます。ブラウザデータ削除に備えてJSONバックアップを取得してください。
- 復帰時ガードはPage Visibility APIと専用遷移フラグで判定し、移動先アプリ名までは判別しません。

## 初期バランス値

- 初期資材10、施設修復費各8、ルート変更費4、開拓プロジェクト費6
- 初期演習目標20問（設定で変更可能）
- 単元攻略：10問以上・正答率70%以上
- 習得：別日の復習で10問以上・正答率80%以上
- 遠征券：学習結果保存時に1枚（探索港修復後、上限3枚）
- XP：解答数・正解数・外部サイト経過時間（最大4XP/日）・初回攻略ボーナス
