# Night Flow MVP

夜のルーティン、基本情報技術者試験の学習、浮遊島の開拓シミュレーションをひとつにつなぐ個人用PWAです。

## 今回の修復内容

### リアルタイム3D浮遊島・施設ビジュアル
- Three.js r187をローカル同梱し、WebGLでリアルタイム3Dシーンを描画します。
- 島の地形は手続き生成メッシュで構成し、岩肌・草地・木材の表面テクスチャ、凹凸、環境反射、フォグ、影、複数の光源を使用します。
- 研究施設は観測塔と青いドーム、探索港は飛行船・係留柱・木製桟橋、生息地は温室・ガラスドーム・内部植生と仲間の生き物を3Dモデルとして描画します。
- 雲の移動、島の浮遊、樹木の揺れ、滝の流れ、飛行船、浮遊粒子を再生ボタンなしで自動アニメーションします。
- ドラッグでカメラ回転、ホイール・ピンチでズームできます。
- 修復済み施設は島に表示され、未修復施設はそれぞれの場所に遺跡として残ります。
- 建設時は施設へカメラが寄る演出と、建設前・建設中・完成の段階を自動再生します。スキップ可能です。
- `prefers-reduced-motion` を尊重し、WebGL非対応時にはSVGシーンへフォールバックします。

> Three.js r187はMITライセンスで `assets/vendor/THREE-LICENSE.txt` を同梱しています。3Dは端末のWebGL/GPU性能に依存します。

### 初回チュートリアル
- 初回起動時に6ステップのガイドを表示します。
- 「次へ」「戻る」「スキップ」に対応し、完了状態はLocalStorageに保存します。
- 設定画面から再表示できます。

### ゲームの目的・メインクエスト
- 物語上の目的を「消えた星渡りの灯台を再点灯し、孤立した浮遊島群の航路をつなぎ直す」と明確化。
- 最初の施設選択→最初の開拓プロジェクト→二つ目の施設→二つ目のプロジェクト→灯台再点灯の5段階。
- ホーム・拠点に現在の目的と次の行動を表示し、プロジェクト画面に最終目標・必要条件を常時表示。
- 灯台再点灯で新しい群島エリア、遺物、XP、資材を獲得。

### 自動学習計画・ガントチャート
- 目標試験日、学習する曜日、1日の学習可能時間、問題数を指定して自動計画を生成。
- 現行シラバスVer.9.2の未習得単元を日付ごとに割り当てる。
- 科目Aを優先し、科目Bを一定間隔で挿入。5学習回ごとに直近単元の復習を組み込む。
- 週ごとのガントチャートに日付・科目・単元・開始予定時刻・所要時間・問題数を表示。
- 試験日までに割り当てきれない単元数を表示し、計画不足を隠さない。
- 今日の学習画面は従来どおり手動変更可能。自動計画は別管理。

### 開拓・報酬の強化
- 研究施設は知識アーカイブ、探索港は遠征、生息地は仲間の育成機能を解放します。
- 探索港の修復後、学習結果の保存で遠征券を獲得します（最大3枚）。
- 遠征先を選び、確定報酬に追加資源・希少遺物が上乗せされる仕組みを追加しました。
- 運要素で失敗したり、表示された最低保証を下回ったり、資材を没収されたりすることはありません。
- 遺物が重複した場合も資材補償があります。

## 起動方法

HTTPSまたはlocalhostで配信してください。`file://`ではService Workerは動作しません。

```powershell
py -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。GitHub Pages への公開は .github/workflows/deploy-preview.yml が担当します。Settings → Pages → Build and deployment → Source を GitHub Actions に設定済みで、main への push 後に自動デプロイします。公開先は [https://keishi-okawa.github.io/night_traning/](https://keishi-okawa.github.io/night_traning/) です。

## 主なファイル

- `index.html`：HTML/CSS/JavaScriptをまとめたアプリ本体
- `manifest.webmanifest`：PWA設定
- `sw.js`：アプリ本体とSVGアセットのオフラインキャッシュ
- `assets/js/island-3d.js`：Three.jsによるリアルタイム3Dシーン・カメラ操作
- `assets/vendor/three.module.js` / `three.core.js`：オフライン同梱のThree.js r187
- `assets/game/island-scene.svg`：WebGL非対応時のフォールバック
- `assets/game/facility-*.svg`：施設カード・チュートリアル用の立体イラスト
- `docs/`：今回の仕様変更書3件

## 既知の制約

- 過去問道場の成績自動取り込みは未実装です。演習結果はNight Flow側で入力してください。
- 3D描画はWebGL対応ブラウザ・GPUに依存します。WebGLが利用できない場合はSVGの静止フォールバックを表示します。
- ガント計画は目標試験日と学習可能日をユーザーが入力して作成します。試験日の未設定時は自動計画を生成しません。
- 自動計画は現行カリキュラムの分類単位で割り当てます。各テーマの説明文・要点の全件自動生成や、過去問道場からの問題自動取得は行いません。
- 過去問道場の分野は外部サイトを開いた後に選択します。非公開APIやスクレイピングには依存しません。
- カリキュラムはIPAシラバスVer.9.2の分類カタログです。すべての要点コンテンツが完成済みという意味ではありません。
- 学習・ゲームデータはLocalStorageに保存されます。ブラウザデータ削除に備えてJSONバックアップを取得してください。
- 復帰時ガードはPage Visibility APIと専用遷移フラグで判定し、移動先アプリ名までは判別しません。ガード画面では現在の目的・次の一歩・元の画面を提示し、明示的な操作で復帰します。

## 初期バランス値

- 初期資材10、施設修復費各8、ルート変更費4、開拓プロジェクト費6
- 初期演習目標20問（設定で変更可能）
- 単元攻略：10問以上・正答率70%以上
- 習得：別日の復習で10問以上・正答率80%以上
- 遠征券：学習結果保存時に1枚（探索港修復後、上限3枚）
- XP：解答数・正解数・外部サイト経過時間（最大4XP/日）・初回攻略ボーナス
